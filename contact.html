How to Submit a Tool

When submitting a new tool, please include:

  • Tool name and GitHub URL
  • A one-sentence description in English (and optionally Chinese)
  • Category: ai-tools, skill, or agent
  • Relevant tags (e.g., llm, rag, code)
  • Why it deserves to be listed (stars, use case, uniqueness)
💡 We only accept open-source tools hosted on GitHub with 1,000+ stars.
