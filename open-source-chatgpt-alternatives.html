How to Set Up Open WebUI in 5 Minutes 5 分钟搭建 Open WebUI 完整指南

Open WebUI with Ollama is the most recommended setup for a private ChatGPT alternative. Here's the complete process: Open WebUI 配合 Ollama 是最推荐的私有 ChatGPT 替代方案。以下是完整部署流程：

1

Install Docker Desktop 安装 Docker Desktop

Download from docker.com for Mac, Windows, or Linux. Docker is required to run Open WebUI in an isolated container. 前往 docker.com 下载适用于 Mac、Windows 或 Linux 的版本。Docker 用于在隔离容器中运行 Open WebUI。

2

Install Ollama (the local model runner) 安装 Ollama（本地模型运行器）

Run the one-line installer below. Ollama handles downloading and running open-source LLMs like Llama 3.2, Mistral, and Gemma locally. 运行以下一行安装命令。Ollama 负责下载并在本地运行 Llama 3.2、Mistral、Gemma 等开源大模型。

3

Pull a language model 拉取语言模型

Llama 3.2 is recommended for first-time users — it runs on 8GB RAM and provides excellent general chat quality. The download is ~2GB. 推荐新用户使用 Llama 3.2——8GB 内存即可运行，通用聊天质量优秀。下载大小约 2GB。

4

Run Open WebUI with Docker 用 Docker 运行 Open WebUI

The command below starts Open WebUI on port 3000. The --add-host flag allows the container to reach Ollama running on your host machine. 以下命令在 3000 端口启动 Open WebUI。--add-host 参数让容器能访问宿主机上的 Ollama 服务。

5

Open your browser and start chatting 打开浏览器，开始对话

Navigate to http://localhost:3000. Create an admin account on first launch, select your model from the dropdown, and start chatting privately. 访问 http://localhost:3000，首次启动时创建管理员账号，从下拉菜单选择模型，即可开始私密对话。

bash Complete Setup Commands 
# Step 2: Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Step 3: Pull a model (Llama 3.2 – recommended for beginners)
ollama pull llama3.2

# Step 4: Run Open WebUI
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart always \
  ghcr.io/open-webui/open-webui:main

# Step 5: Open browser
# Visit: http://localhost:3000

Frequently Asked Questions 常见问题

What is the best free alternative to ChatGPT? ▾
Open WebUI with Ollama is the most popular free ChatGPT alternative, with over 140,000 GitHub stars. It runs 100% locally, supports all major open-source models like Llama 3.2 and Mistral, and provides a polished chat interface similar to ChatGPT. For the quickest setup, ChatGPT Next Web (one-click Vercel deploy) is the easiest to get running in under 5 minutes.
Can I run a ChatGPT alternative without an API key? ▾
Yes. Tools like Open WebUI, Jan, PrivateGPT, and AnythingLLM run entirely locally using Ollama or llama.cpp — no API key required. You download a model once (e.g., ollama pull llama3.2) and all inference happens on your machine. The only requirement is sufficient RAM: 8GB for 7B models, 16GB+ for 13B+ models.
Is Open WebUI better than ChatGPT? ▾
For privacy and cost, Open WebUI wins: it's free, runs locally, and never sends data to third parties. For raw capability and ease of use, ChatGPT (especially GPT-4o) still leads — its coding, reasoning, and multimodal capabilities are more advanced than most open-source models. Open WebUI is ideal if privacy, cost, or self-hosting flexibility is your priority.
Which open source ChatGPT alternative supports document upload? ▾
AnythingLLM and PrivateGPT are the best choices for document Q&A. AnythingLLM supports PDF, Word, CSV, and web URLs, with a built-in vector database. PrivateGPT focuses specifically on querying your documents with 100% local privacy. Open WebUI also has RAG capabilities built-in for document uploads within the chat interface.
Are these ChatGPT alternatives completely free? ▾
Yes, all tools listed here are open-source and free to use. The only cost is the hardware (your own computer or a VPS). Tools using local inference like Open WebUI + Ollama have zero ongoing costs. API-based tools like ChatGPT Next Web and LobeChat are also free software, but require you to supply your own API key — which has usage costs from the API provider (e.g., OpenAI, Anthropic).
