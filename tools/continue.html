What Is Continue? Continue 是什么？

Continue is an open-source project with 35k+ GitHub stars. Licensed under Apache-2.0. Open-source AI code assistant for VS Code and JetBrains

The project focuses on code, ide, productivity use cases and is designed as a ready-to-use application—you can deploy or run it directly without writing integration code.

Source code is available at github.com/continuedev/continue. With 35k+ GitHub stars, it ranks among the most battle-tested open-source tools in this space—meaning most common use cases are well-documented with community solutions available.

Continue's 35k+ stars reflect its strength for developers migrating from GitHub Copilot who need local-first inference without vendor lock-in. Unlike Copilot's cloud dependency, Continue processes code locally, reducing latency and privacy concerns. However, teams requiring sophisticated multi-file refactoring should evaluate commercial alternatives, as open-source tooling here remains less mature.

Key Features 核心功能

  • 🔌
    LLM Provider Flexibility — Connect to Ollama, OpenAI, Anthropic, or custom endpoints without vendor lock-in. Switch models and providers by editing config files.
  • ⚙️
    Config-Driven Customization — Define custom system prompts, context providers, and slash commands via JSON configuration. Tailor behavior to your team's coding standards.
  • 💻
    Dual IDE Support — Native extensions for both VS Code and JetBrains IDEs. Consistent AI-assisted coding experience across your entire development toolkit.
  • 🔓
    Fully Open-Source — Audit, fork, and modify the complete source code. No proprietary dependencies mean full transparency and community-driven development.
  • 📝
    Context-Aware Prompting — Customizable context providers automatically inject relevant code files, documentation, and codebase context into AI requests for smarter suggestions.

Pros & Cons 优缺点

✓ Pros优点

  • Open-source VS Code and JetBrains extension for AI-assisted coding
  • Works with any LLM — Ollama, OpenAI, Anthropic, or custom endpoints
  • Highly customizable with config files for system prompts and context providers
  • Free alternative to GitHub Copilot that works with local models

✕ Cons缺点

  • Quality of suggestions depends entirely on the underlying model — much better with GPT-4o/Claude than smaller local models
  • Fewer pre-built integrations than GitHub Copilot
  • Less polished UI compared to Cursor's native IDE experience

Frequently Asked Questions 常见问题

What is Continue? ▼
Continue is an open-source AI coding assistant extension for VS Code and JetBrains IDEs. Unlike GitHub Copilot, it works with any LLM provider including local Ollama models, making it a flexible, privacy-preserving alternative.
Is Continue free? ▼
Yes, Continue is Apache 2.0 licensed and completely free. You only pay for the LLM API you connect it to — use Ollama with local models for zero API costs.
Continue vs GitHub Copilot — which is better? ▼
GitHub Copilot has better out-of-the-box quality and broader IDE support. Continue is more flexible (any model), open-source, and free. For developers who want to use local or custom models, Continue is the right choice. For those who want the best quality without configuration, Copilot is more polished.
