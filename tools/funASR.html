What Is FunASR?

FunASR is an open-source end-user AI application with 6k+ GitHub stars. Fundamental end-to-end speech recognition toolkit

As a end-user AI application, FunASR is designed to help developers and teams integrate AI capabilities into their projects without building everything from scratch. It provides a ready-to-use interface that reduces the time from idea to working prototype.

The project is maintained on GitHub at github.com/modelscope/FunASR and is actively developed with a strong open-source community. Its 6k+ GitHub stars reflect significant community validation and adoption.
