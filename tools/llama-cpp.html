llama.cpp is the foundational C/C++ engine that makes running LLMs locally possible. No Python, no CUDA requirement, no heavy frameworks—just fast, portable inference that powers Ollama, LM Studio, and countless other tools.

What Is llama.cpp?

llama.cpp is created by Georgi Gerganov and enables LLM inference without Python, PyTorch, or any ML framework. It compiles to a single binary that runs on virtually any hardware: x86 CPUs, Apple Silicon, NVIDIA GPUs, AMD GPUs, even Raspberry Pi.

The project introduced GGUF (GGML Unified Format)—a quantized model format that dramatically reduces memory requirements. A 7B parameter model that normally requires 14GB RAM can run in 4GB using Q4 quantization.

Key Features

  • ⚡
    GGUF quantization — Q4, Q5, Q8 quantization levels trade a small quality loss for 2-4× memory reduction. Essential for running large models on consumer hardware.
  • 🍎
    Apple Silicon Metal — Native Metal GPU acceleration on M1/M2/M3 chips delivers 50-100 tokens/sec on 7B models—comparable to NVIDIA RTX 3080 performance.
  • 🌐
    llama-server — Built-in HTTP server with OpenAI-compatible API. Expose llama.cpp as a REST endpoint for any application.
  • 🐍
    llama-cpp-python — Official Python bindings. Use llama.cpp from Python with a simple API that mirrors the OpenAI SDK format.
  • 🔢
    Multi-GPU support — Distribute model layers across multiple GPUs for running large 70B+ models that don't fit on a single GPU.
  • 📊
    100+ model support — Llama, Mistral, Gemma, Phi, Falcon, Qwen, Yi, and every major open model family.

GGUF Quantization Guide

Q4_K_M
Best
Quality/size balance. Recommended default.
Q5_K_M
High Quality
20% larger than Q4, slightly better output.
Q8_0
Near-Lossless
Largest GGUF. Use if RAM allows.
Q3_K_M
Small
For RAM-constrained devices. Quality drops.

Python Usage

pip install llama-cpp-python

from llama_cpp import Llama

llm = Llama(model_path="./llama-3-8b-Q4_K_M.gguf", n_gpu_layers=-1)
output = llm("What is the capital of France?", max_tokens=100)
print(output['choices'][0]['text'])

Frequently Asked Questions

llama.cpp vs Ollama: which should I use? ▼
Use Ollama for ease of use—it wraps llama.cpp with a friendly CLI and API. Use llama.cpp directly when you need maximum control, want to embed inference in a C/C++ application, or need custom compilation flags for specific hardware optimization.
What quantization should I use? ▼
Q4_K_M is the best balance for most users. If you have extra RAM, use Q5_K_M or Q8_0 for better quality. For RAM-limited devices (≤8GB), use Q3_K_S or Q4_0 for smaller models.
Where do I download GGUF models? ▼
HuggingFace (huggingface.co) is the primary source. Search for "[model-name] GGUF". Bartowski and TheBloke are popular HuggingFace users who publish many GGUF-quantized models. Filter by quantization level to find the right file size.
Can I use llama.cpp on a Mac? ▼
Yes, llama.cpp has excellent macOS support with Metal GPU acceleration for Apple Silicon (M1/M2/M3). Install via Homebrew: `brew install llama.cpp`. Apple Silicon Macs achieve 50-100 tokens/sec on 7B models.
