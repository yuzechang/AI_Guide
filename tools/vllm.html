What Is vLLM?

vLLM is an open-source LLM inference and serving engine developed by the Sky Computing Lab at UC Berkeley. Its core innovation is PagedAttention—a memory management algorithm that dramatically increases GPU utilization under concurrent request loads.

While tools like Ollama and llama.cpp are designed for individual developers running models locally, vLLM targets production API deployments where hundreds or thousands of users send requests concurrently.

PagedAttention: The Core Innovation

Traditional LLM serving pre-allocates a fixed KV (key-value) cache for the maximum sequence length. This wastes GPU memory—often 60-80% of allocated VRAM is never used. PagedAttention manages the KV cache in fixed-size blocks (like OS virtual memory pages), eliminating fragmentation and enabling near-100% GPU memory utilization.

The result: vLLM can serve 24× more requests per GPU second than HuggingFace Transformers, making it the most cost-efficient option for production deployments.

Key Features

  • 📄
    PagedAttention — Memory-efficient KV cache management. Enables 24× higher throughput under concurrent load vs naive implementations.
  • 🔄
    Continuous batching — Dynamically adds new requests to in-progress batches. Maximizes GPU utilization without waiting for batch completion.
  • 🌐
    OpenAI-compatible API — Drop-in replacement for the OpenAI API. Serve any supported model through the same interface your existing code uses.
  • 💡
    Speculative decoding — Use a small draft model to predict multiple tokens ahead, then verify with the large model. Reduces latency by 2-3× for generation tasks.
  • 🔢
    Tensor parallelism — Automatically distribute large models across multiple GPUs. Run 70B models on 4× A10G GPUs seamlessly.
  • 🤗
    HuggingFace integration — Load any HuggingFace model with `vllm serve meta-llama/Llama-3-8b-instruct`.

Quick Start

# Install
pip install vllm

# Start server (OpenAI-compatible)
vllm serve meta-llama/Llama-3.1-8B-Instruct

# Query with OpenAI SDK
from openai import OpenAI
client = OpenAI(base_url="http://localhost:8000/v1", api_key="none")
response = client.chat.completions.create(model="Llama-3.1-8B-Instruct", ...)

Frequently Asked Questions

What is PagedAttention? ▼
PagedAttention manages the KV cache in fixed-size memory blocks, inspired by OS virtual memory paging. This prevents GPU memory fragmentation that wastes 60-80% of VRAM in traditional serving. The result is near-100% GPU utilization and 24× throughput improvement under concurrent load.
vLLM vs Ollama: when to use which? ▼
Use Ollama for local development and personal use—it's easier to set up and works on CPU. Use vLLM for production deployments serving multiple concurrent users—it's far more efficient at scale. Many teams use Ollama locally and deploy vLLM in production.
How does speculative decoding work? ▼
Speculative decoding uses a small "draft" model to predict multiple tokens ahead. The large model then verifies all predictions in parallel. If most predictions are correct, effective tokens per second increases 2-3× because most generation happens on the fast small model.
Does vLLM support quantized models? ▼
Yes. vLLM supports AWQ, GPTQ, and SqueezeLLM quantization formats. These reduce VRAM requirements while maintaining most of the model quality. GGUF format (used by llama.cpp) is not supported—use AWQ-quantized models from HuggingFace instead.
